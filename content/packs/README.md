# Content Packs

Content packs for RiftCrowd LIVE game modes. Each `<mode>/` directory holds one JSON content pack per the schema in [docs/CONTENT_PACK_FORMAT.md](../../docs/CONTENT_PACK_FORMAT.md) plus its original placeholder SVGs under `<mode>/svg/` (`<pattern>.svg` per faction and `pack_icon.svg`). The four launch packs (Phase 4) are `countries_launch`, `animals_launch`, `fan_crews_launch`, and `cities_launch`. Validate with `npm run validate:packs` from the repository root.
