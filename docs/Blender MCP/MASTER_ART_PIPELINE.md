# MASTER ART PIPELINE

## Goal

Build RiftCrowd LIVE using reusable modular assets.

## Pipeline

1.  Concept reference
2.  Blender MCP planning
3.  Base mesh
4.  Modular armor
5.  Materials
6.  Weapons
7.  Rigging
8.  Animation
9.  Environment
10. Optimization
11. Export to GLB
12. Import into Godot

## Rules

-   Never duplicate reusable meshes.
-   Validate before modifying.
-   Keep naming consistent.
-   Export with transforms applied.
